# v0.4.0

Upgrade from v0.3.0. This release changes host prompt assembly and adds tool
sources and Go provider-managed delegation.

## Renamed, retired and new inputs

Move prompt assembly into the adapter's host injection points: `brief()`,
`memoryFor(query)` (once per run) and bounded `projectInstructions()`. Remove the
host's extra prompt reading/append behavior and the v0.2.0 recall-rule machinery.
The adapter now owns the complete layered request.

Remove the `memory` argument from TypeScript `contextPolicy` / Go `ContextPolicy`;
`budget/memory.json` and the separate brief/memory input reserves are retired.
Count the host parts once where placed instead of subtracting the old reserves.

Declare each external host tool with its source record, effect, approval policy,
version or approved tool-list digest, and executor. Read receipts/proposed marks
by call id. Support catalogue/load when using the schema budget. Do not execute a
`propose` tool as an act; external acts require approval by default.

For the Go agent capability, implement the provider-run callback and durable
checkpoint acknowledgement. Return the provider invocation before dispatching
serial children or continuing the parent; certify the real bridge with `AgentHost`.

## Records and refusals

Preserve prompt digests, source figures and delegation `handoff` in checkpoints;
read optional `delegation_requested.callId`. Resume explicit continuations rather
than replaying committed operations. Respect source schema/argument limits,
changed digest withholding, reserved names and phase/profile ceilings. Re-approve
changed declarations before exposing them again. The notes do not claim backward
readability of these records by older readers.
