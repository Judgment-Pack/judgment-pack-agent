# v0.3.0

Upgrade from v0.2.0. The original tag's notes describe the adapter changes;
the current notes also carry the later factual clarification that `go/v0.3.0` was
made by hand on the release commit.

## Host changes

Offer the optional Deep Agents engine through `@judgment-pack/harness/deepagents`.
Clear LangChain/LangSmith tracing environment variables before using that engine;
the adapter refuses configuration containing them before creating an agent.
Its model transport remains the host's relay and all tools use the package gate.

For Go adoption, bind the Eino adapter to the host's own relay handler, retain
`go.sum` and install `github.com/Judgment-Pack/judgment-pack-agent/go@v0.3.0`.
The package's scripted certification is not certification of that host binding.
Hold host approval handling to `approval/grant-states.json`; provide only the
narrow gated adapter handle, including when a child begins in Plan mode.

## Records and refusals

Use the generated Go contract types and shared schemas/vectors. The notes do not
enumerate a renamed member or record-version migration for existing TypeScript
hosts; that absence is not a downgrade guarantee. Unoffered calls and tracing
configuration refuse; correct configuration and declared offers before dispatch.

## Evidence and adoption

Based on the [release notes](../releases/v0.3.0.md) and [tagged source](https://github.com/Judgment-Pack/judgment-pack-agent/tree/v0.3.0). These guides were backfilled later; their presence does not alter historical release artifacts.

Verify the release asset attestation/checksum before changing the host digest pin;
for Go releases retain the corresponding module version and `go.sum`. Review
intervening guides when skipping versions.
