# v0.7.0

Upgrade from v0.6.0. Migrate the critic control to `critic: off | auto | on`.

## Host inputs and presentation

Replace the composer's boolean review control with the three modes. Supply the
project setting and table default separately; run overrides project overrides
table (`auto`). Set `criticReasoning` explicitly where desired; the critic uses at
least the author's tier unless the host explicitly lowers it. The historical
`adversarialReview` boolean remains a compatibility alias in this release's notes;
new hosts should use `critic` (the alias is refused in v0.9.1).

Display `critic_decided` and checkpoint `critic` including mode, ran, reason,
reasoning and trigger. A failure/pause before the decision point may omit them.
Preserve a pending review request on resume. Account for the native invocation
reserved for the critic under `auto`/`on` when displaying delegation capacity.

## Refusals and records

`request_review` is reserved and admitted once per run in the author's phase
under `auto`; other uses refuse with a guardrail. Human review assignment, graph,
Plan and children turn the critic off with a reason. Do not treat model prose or
retrieved text as a mode change. The notes name no record-format version change;
they do not establish a general downgrade guarantee.
