# v0.9.1

Upgrade from v0.9.0. Migrate all three retired input forms before upgrading.

## Renamed and retired inputs

- Replace `adversarialReview` / Go `Run.Review` with `critic` / `Critic` (`on`,
  `off`, `auto`) or `policy.critic.default`. Presence of the old member refuses,
  including false and alongside its replacement.
- Replace the flat `budget.json` policy layer with `policy.budget`. Move
  `criticDefault` to `policy.critic.default` and `criticReasoningFloor` to
  `policy.critic.reasoningFloor`. Retired root members also refuse beside canonical ones.
- Replace bare-text memory (even empty text) / Go `MemoryForFunc` with closed
  `Memory[]` / `MemoryRecordsForFunc`. Null/nil/undefined means no memory.

## Source API migrations

TypeScript request builders read `session.values`, use `forRole` for roles and
`withModel` for admitted model names. Controller reads are detached snapshots;
write with `controller.mutate`. Go builders use `RequestSession` getters such as
`ModelID`, `Family`, `AgentCapability`, `PolicyBinding`, `ResolvedCapabilities`,
`RuntimeTools` and `OfferedHostTools`; replace writes through `State()` with
`MutateCheckpoint`. These source migrations preserve wire/member shapes.

## Optional inputs, records and refusals

Optionally provide metadata-only `memoryLifecycle` / `MemoryLifecycleFunc` to report
forgotten identities across resume; retain canonical metadata, not deleted prose.
Identity rewrites, contradictory recall and resurrection refuse atomically.

For a fixed API allowance supply TypeScript `context.requestCap` / Go
`Input.RequestCap` (integer 1–20) before setup and independently on resume.
Checkpoint `requestCap` is optional, but older open readers can mistake cap 20 for
an extendable allowance. Use compatible readers and the newest durable checkpoint,
serialize admission and account for transport retries. Extension, inconsistent
resume identity, invalid `LimitTo`, native invocation caps and zero-room children
refuse. Omission retains legacy defaults and bounded grants. Durable claims do not
promise globally exactly-once delivery.
