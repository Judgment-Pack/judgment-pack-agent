# v0.1.0

This is the initial package adoption guide, not an upgrade from an earlier
published harness release. Replace the Desk's in-tree assistant with the verified,
digest-pinned tarball; there is no registry package.

## Host changes

Bind the host seams for model/agent execution, tool calls, approvals, memory and
context to the extracted package. Select the Vercel or Codex entrypoint and certify
the binding with the shared contract. Key custody, relay ownership and Runtime
rehearsal remain host responsibilities. Apply the bounded read-window/search,
provider-capability, image and retry behavior described in the release notes;
external tool execution still passes through the gate.

## Records and refusals

Adopt the release's run-event, tool-call/result, budget and checkpoint schemas.
This first package release supplies no earlier-package record migration promise.
Unoffered tools, non-rehearsal evaluation and out-of-bounds inputs refuse; migrate
callers to the offered tools and bounded inputs rather than bypassing those checks.

## Evidence and adoption

Based on the [release notes](../releases/v0.1.0.md) and [tagged source](https://github.com/Judgment-Pack/judgment-pack-agent/tree/v0.1.0). These guides were backfilled later; their presence does not alter historical release artifacts.

Verify the release asset attestation/checksum before changing the host digest pin;
for Go releases retain the corresponding module version and `go.sum`. Review
intervening guides when skipping versions.
