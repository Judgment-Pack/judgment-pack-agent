# v0.8.1

Upgrade from v0.8.0. This patch fixes packed import closure and Gemini
fallback model-path encoding; its notes explicitly state no contract change.

## Host changes

Replace the installed tarball and digest pin, then rebuild the consumer bundle;
v0.8.0's corpus import escaped the installed package. Keep consuming this release
through a bundler. Direct native Node ESM remains unsupported at this version
(the native ESM migration arrives in v0.9.0).

The Go module's behavior change is Gemini model ids encoded as one RFC 3986 path
segment. Keep model ids as input values rather than pre-encoding them in the host.

## Records and refusals

The release notes state the wire contract and policy table are unchanged. They
specify no renamed/retired member, new required host input or record migration;
this is the stated patch scope, not a broader compatibility assessment.
