# v0.9.0 dependency applicability and disposition

Assessment date: 2026-10-23. The maintainer accepted the bounded braces
dependency-risk deferral below for v0.9.0 on this date, with upstream remediation
tracked separately in [#161](https://github.com/Judgment-Pack/judgment-pack-agent/issues/161)
under milestone v0.9.1. This acceptance is not security remediation or completion
of the other release gates. The online npm audit before this patch reported 13 affected
package entries; these are not 13 independent vulnerabilities. The final lockfile
reports four high-severity entries, all deriving from the same unfixed braces
advisory. No source, admission, verdict, or tool-gate policy changes accompany this
patch.

## Compatible updates

The published harness manifest pins `@modelcontextprotocol/sdk` to 1.32.1
(previously 1.30.0). Development pins move esbuild 0.28.0 → 0.28.2 and Vite
8.2.2 → 8.2.4. Normal compatible npm resolution refreshes fast-uri to 3.1.9,
proxy-addr to 2.0.8, qs to 6.16.1, Hono to 4.13.13, ip-address to 10.7.4, and
source-map-js to 1.2.2. The resolver selected newer patches of fast-uri, qs and
Hono than the initially reviewed minimum-fixed candidates; the online audit
confirms these versions clear the corresponding entries. Their engine requirements
remain compatible with Node 22. No overrides or artificial direct dependencies
are added. esbuild's platform packages follow its exact 0.28.2 dependency pins.

The SDK manifest pin travels with the published tarball. The six transitive
refreshes are repository lockfile hygiene: tarball consumers must update and audit
their own resolved application graph. This root lockfile does not impose transitive
version floors on external installations.

## Accepted braces deferral and native/bundled boundaries

The harness explicitly imports `deepagents/browser` in
[loop.ts](../../packages/harness/engines/deepagents/loop.ts#L32), retained in both
emitted native ESM and browser paths. Its shared chunk imports micromatch, which eagerly loads
braces. Native loading and real consumer bundles may therefore contain vulnerable
code; module presence is not excluded by this assessment. The package build does
not bundle dependencies, and the packed browser smoke externalizes them.

The observed Deep Agents browser call sites use only `micromatch.isMatch`, which
calls picomatch rather than braces' vulnerable recursive compile/expand walkers.
The separate Deep Agents Node/root backend chunk imports fast-glob; that path can
reach `micromatch.braces(..., { expand: true })`, but the harness's explicit browser
subpath does not import it, including under native Node resolution.

The harness also replaces filesystem, subagent, summarization and patch-tool-call
middleware by name with empty middleware, supplies a lazy StateBackend and
replaces tool execution at its gate. See the
[built-in replacement names](../../packages/harness/engines/deepagents/loop.ts#L127),
[empty middleware construction](../../packages/harness/engines/deepagents/loop.ts#L174),
[tool boundary](../../packages/harness/engines/deepagents/loop.ts#L160) and
[agent middleware/backend configuration](../../packages/harness/engines/deepagents/loop.ts#L779).
Default factories construct definitions and
closures without globbing; skills/memory middleware are not configured. The
current vulnerable walkers and fast-glob operations are therefore installed but
not exercised by these reviewed, configured harness paths. Vulnerable code remains
installed. The maintainer accepted this bounded release risk on 2026-10-23 and
superseded the earlier release hold; this does not establish general immunity to
denial of service or approval of host-owned filesystem tools. The audit's suggested
Deep Agents downgrade is not applied.

Reassess if imports change to `deepagents` or `deepagents/node`, built-ins,
skills/memory/backend features are enabled, or another caller invokes
micromatch.parse/braces/braceExpand or fast-glob on untrusted patterns. External
server/transport/API usage requires separate assessment. No exploitation proof or
whole-host safety claim is made.

## Upstream follow-up

[#161](https://github.com/Judgment-Pack/judgment-pack-agent/issues/161) tracks
reassessment for v0.9.1. As checked on 2026-10-23, upstream
[deepagentsjs#925](https://github.com/langchain-ai/deepagentsjs/pull/925) remains
open, has merge conflicts and has no reviews. Build/lint/format and Ubuntu/Windows
Node 22/24 unit checks passed; integration checks were skipped and Vercel deployment
failed for lack of authorization. These checks do not verify a security fix.

The proposal replaces the micromatch/fast-glob/braces dependency path with
picomatch/fdir, adds pattern limits and changes symlink traversal behavior; it is
not a patch to the braces library. Published stable Deep Agents 1.15.1 still
depends on micromatch `^4.0.8` and fast-glob `^3.3.3`. No preview or upstream patch
is adopted or verified here. Reassess compatibility and the actual consumer
dependency graph after an upstream review, merge and release.
