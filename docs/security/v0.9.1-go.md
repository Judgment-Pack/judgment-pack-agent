# v0.9.1 Go dependency assessment (#188)

The release preflight found Go standard-library advisories under the repository's Go 1.26.5
build toolchain and affected imported module versions. The build and CI pin moves to
[Go 1.26.10](https://go.dev/doc/devel/release#go1.26.10). The root module selects jsonparser
1.1.2 for [GO-2026-4514](https://vuln.go.dev/ID/GO-2026-4514.json) and x/sys 0.44.0 for
[GO-2026-5024](https://vuln.go.dev/ID/GO-2026-5024.json); the package dependency allow-list
names those exact versions. The public `go 1.25.0` minimum is retained. The Go 1.26.10
build pin does not require consumers to change that minimum.

## Artifact and regression evidence

The actual Linux/amd64 Go archive was checked against the
[official download metadata](https://go.dev/dl/?mode=json&include=all): SHA-256
`ccfe7ae822d2c2f41f4fe7c956199967a4dac22d0ee0d2b2bfdb440aab3b20c5`. The unpacked driver and
compiler identify as Go 1.26.10. Both exact module downloads match their recorded Go module
checksums. jsonparser 1.1.2 declares Go 1.13; x/sys 0.44.0 declares Go 1.25.0. The resolved
imported module versions change only these two selections; existing checksum entries are retained.
The graph-only selections also move to x/mod 0.40.0, x/text 0.41.0 and yaml.v2 2.2.8.
They retain the language minimum and leave all 28 imported-module versions unchanged.

The handwritten `TestJSONParserDeleteMalformedInput` covers missing values, truncated objects,
malformed arrays and a valid deletion. Its truncated-object row panics with jsonparser 1.1.1;
the fixed version preserves malformed input and keeps the valid deletion behavior. The check
calls the upstream API directly because Delete is not used by the harness's current callers.
This guards the selected dependency's reported correction without claiming every malformed
JSON input is supported. The repository's depcheck tests passed: 417 packages from 28 external modules, all admitted.
The Eino adapter probe passed after the coordinator completed the matching development dependency
projection. The baseline remediation passed all 23 local checks under Go 1.26.10; the bounded
graph-only follow-up is verified separately and by CI.

The x/sys correction checks that the UTF-16 byte length, including its terminator, fits in
uint16 before constructing an NTUnicodeString. Source and artifact/version evidence were
checked on Linux; the Windows-only runtime regression was not executed. The public Go 1.25
minimum was checked against resolved metadata, not by running a separate Go 1.25 compiler.

## Remaining release decision

This change does not clear the release. The earlier official symbol scan reported fourteen
unique standard-library advisory IDs under Go 1.26.5; the highest fixed 1.26-series version is
1.26.10 ([GO-2026-6809](https://vuln.go.dev/ID/GO-2026-6809.json)). That evidence remains the
negative control; the final candidate needs a fresh audit after integration.

The remaining affected graph selections are x/crypto, x/net and rsc.io/pdf. None of those
families appeared in the initial Linux/amd64 root module
package/test closure (417 packages, 29 modules, zero listing errors). This is bounded package
reachability evidence, not a disposition for other platforms, build tags, the separate spike
module, or dependencies' own tests and generator commands. Current
[crypto/openpgp](https://vuln.go.dev/ID/GO-2026-5932.json) and
[rsc.io/pdf](https://vuln.go.dev/ID/GO-2026-5781.json) advisories have no fixed versions.

Upstream fixes or owning-path removal remain preferred. Remaining graph dispositions are
**open** under the [dependency policy](dependency-policy.md). No advisory suppression or
maintainer reachability exception is granted by this change. The final release review must
record the resolved remedies and any explicit bounded maintainer decision.
