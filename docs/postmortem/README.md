# Postmortems

Write a short, numbered record after a release audit exposes a repeated failure
class or a release claim that the available evidence did not establish. Use the
next four-digit number and a descriptive filename. Link the review evidence;
separate observed behavior, why existing checks missed it, and the structural
change that prevents recurrence. Record remaining limits. Describe mechanisms
and evidence rather than assigning personal blame.
