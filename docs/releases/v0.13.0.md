# v0.13.0

The v0.13.0 tag (commit `e8436e2`) was never published. The release evidence gate refused it
twice during a staged hosted-image roll
([#332](https://github.com/Judgment-Pack/judgment-pack-agent/issues/332)), and a tag is never
moved or reused, so no release, package tarball or `go/v0.13.0` tag of the Go module
`github.com/Judgment-Pack/judgment-pack-agent/go` was made from it.

Its content is released as [v0.13.1](v0.13.1.md), whose notes and
[host upgrade guide](../upgrade/v0.13.1.md) replace this release's. This file and the
[v0.13.0 guide](../upgrade/v0.13.0.md) remain because the tag exists. The
[dependency inventory at the tag](https://github.com/Judgment-Pack/judgment-pack-agent/blob/v0.13.0/docs/dependencies.md)
is the tag commit's.
