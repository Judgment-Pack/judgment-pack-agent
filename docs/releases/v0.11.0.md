# v0.11.0

Candidate release notes; v0.11.0 is not yet published.
The package is `@judgment-pack/harness`. A completed release is expected to publish
its attested npm tarball and checksums and create the matching Go module tag
`go/v0.11.0` on the release commit for module
`github.com/Judgment-Pack/judgment-pack-agent/go`. The workspace package and
lockfile now identify the 0.11.0 candidate. Publication,
release assets, attestations and matching tags remain release gates.

## Candidate scope

The candidate contains versioned checkpoint/event/policy readers, task-aware plans,
repeated-tool controls, per-turn routing, optional usage budgets, retained history,
feedback and archive/capture APIs, and tool-taxonomy and dialect-authoring surfaces.
These are candidate implementation areas, not a statement that their final release
gates have passed. The host migration details are in the [host upgrade guide](../upgrade/v0.11.0.md).

Archive1 is the candidate retained-history archive shape; unpublished archive
prototypes have no promised compatibility. Imported archives are detached,
read-only display data and cannot resume or execute a run. The candidate does not
supply a persistent host store or scheduler. ADR-0025's unattended-run build items
#223–#230 are assigned to v0.12.0 and are not claimed here.

## Host review before pinning

Upgrade readers before writing feature-bearing records. Feature-free checkpoint,
event and report outputs retain their existing formats; opt-in features may write
checkpoint 3, event 2, policy 2 or report 2 as described in the guide. Review the
storage ownership, archive read-only constraints and explicit per-feature defaults
before enabling a capability.

  `Draft RFC0029` at reviewed Spec source
  `ade3914b0b81ef299e5b9a8d6147f37ff3f0976c`, schema
  `sha256:996cec17473987eebf1aa553536df0ce5a740971532567f411282ee70036879f`
  and corpus
  `sha256:e2ac53f56cd5ab779e032d2847b49fa04438ffb9df57d456f75f2ba058dc12d2`.
  [Spec PR271](https://github.com/Judgment-Pack/judgment-pack-spec/pull/271)
  merged that Draft through squash `25b7156a1a27fd46d1b2493145a6e9fb5931a2f5`;
  the selector deliberately retains the reviewed source identity. Paired focused
  TypeScript/Go probes against an actual development Runtime verify the complete
  generated document and digest against a handwritten expectation. They do not
  establish normative adoption, published Runtime support or final Agent artifact
  pairing. Runtime v0.39.0-alpha.1 predates these additional retained-column changes.
- **Taxonomy producer artifacts — published; Agent integration pending.** Gateway
  v0.22.0-alpha.1 and Runtime v0.39.0-alpha.1 publish the #324/#329 producer
  metadata under the scoped alpha decision. The producer pair has bounded verification;
  this does not establish final Agent integrated CI/review or final artifact pairing.
- **Routing — implementation/focused acceptance verified; release gates pending.**
  Routing is implemented and bounded focused acceptance passed. Integrated CI, review
  and final release evidence remain required. Keep routing off by default; no
  evidence-based recommendation to enable `auto` is claimed.
- **Runtime action approval — producer artifact published; final Agent pairing pending.**
  Runtime v0.39.0-alpha.1 is immutable and verified. Its bounded consumer evidence
  does not prove final Agent integrated CI/review or published support for the
  additional #171 retained-column contract.
- **Dependency disposition — pending final evidence.** Record the candidate
  commit, query time,
  npm audit coverage/result and each finding's disposition. Assess Go and Python
  dependencies separately, link current primary evidence and explicit unexpired
  maintainer approvals where applicable. The offline fixture check is not a live
  advisory assessment.
- **Capture/export — implementation/focused checks verified; release gates pending.**
  Optional transcript-v1 capture metadata and projection are implemented and paired
  focused-verified. Integrated CI, review and final release evidence remain required;
  this does not claim live-provider comparison or whole-issue acceptance.
- **Release validation — pending.** Record the exact candidate commit and dirty diff,
  full required check summary, exact-head CI, full mutation coverage, independent
