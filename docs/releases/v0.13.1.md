# v0.13.1

The v0.13.1 tag (commit `1c60cdc`) was never published. The release evidence gate refused it
during the same staged hosted-image roll that refused v0.13.0, this time under the CI jobs
([#336](https://github.com/Judgment-Pack/judgment-pack-agent/issues/336)), and a tag is never
moved or reused, so no release, package tarball or `go/v0.13.1` tag of the Go module
`github.com/Judgment-Pack/judgment-pack-agent/go` was made from it.

Its content is released as [v0.13.2](v0.13.2.md), whose notes and
[host upgrade guide](../upgrade/v0.13.2.md) replace this release's. This file and the
[v0.13.1 guide](../upgrade/v0.13.1.md) remain because the tag exists. The
[dependency inventory at the tag](https://github.com/Judgment-Pack/judgment-pack-agent/blob/v0.13.1/docs/dependencies.md)
is the tag commit's.
