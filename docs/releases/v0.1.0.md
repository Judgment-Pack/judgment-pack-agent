# Agent harness v0.1.0

The first release of `@judgment-pack/harness`, the agent harness behind Judgment Pack Desk, as an
attested package asset. It is the swap-ready release: a harness the Desk can install in place of
its in-tree assistant, pinned by digest in its component lock. There is no registry package.

## What the package is

The Desk's assistant loop, extracted with no behaviour change and held behind one wire contract
([ADR-0001](../adr/0001-one-contract-many-adapters.md)): the context budget and ledger, execution
and planning, delegation, the memory client, the tool gate, the failure catalogue, and the host
module through which a host supplies what the package needs.

- The **Vercel AI SDK adapter** (`@judgment-pack/harness/vercel`), extracted as the Desk runs it
  today.
- The **Codex adapter** (`@judgment-pack/harness/codex`), the ChatGPT-subscription engine, as a
  second adapter of the same contract.
- The **wire contract** (`@judgment-pack/harness/contract` and `contract/`): language-neutral JSON
  schemas and vectors for run events, tool calls and results, approvals, failures, budgets and
  provenance.
- The **certification suite** (`@judgment-pack/harness/certification`), run against each adapter:
  `npm run certify -- --adapter <id>`. Both adapters pass it at this release.

What stays the host's does not move: the keyless model relay and key custody, the tool gate's
approvals, and the Runtime tools' rehearsal rule.

## What v0.1.0 holds

The milestone "v0.1.0: swap-in ready":

- #19, the wire contract extracted from the Desk's engine slot.
- #20, the Vercel AI SDK adapter.
- #21, the certification suite.
- #22, this package and its attested release.

Parity with the Desk's harness is the goal of this release, not new behaviour.

## What it does not hold

The improvements of #1 to #18 (retries and limits, failure-path tests, caching and memory, search
and reads, delegation, and the rest) did not land in this release and follow the swap. Also not
held, unless it is closed before the tag: #25, the certification gap around the gate's ceiling.

## Installing and verifying
