# v0.3.0

The third release of `@judgment-pack/harness`, as an attested package asset, after the Desk adopted v0.2.0 (judgment-pack-desk#531). It holds the two adapters ADR-0001 planned after the Vercel and Codex ones: the Deep Agents JS adapter, and the Go train's first steps toward a server-side adapter. Each change was reviewed in a clean-room round recorded on its pull request, and the whole release diff in one clean-room review recorded on the release-prep pull request. There is no registry package.

## What v0.3.0 holds

- **The Deep Agents JS adapter** (`@judgment-pack/harness/deepagents`, #47, ADR-0003, proposed): a third certified engine with the `model` capability, built on `deepagents/browser` with every built-in middleware switched off, its own chat model whose only way out is the host's relay, every tool call through the package's gate on the native and the text paths, delegation, context, budget and events the package's own; it passes the full certification on every leg and the six scenarios; a run whose environment sets any LangChain or LangSmith tracing variable is refused as a configuration failure before the agent is built, with a sealed certification leg proving zero reaches; its recorded differences from the Vercel adapter are in `docs/design/wire-contract.md`. Adds about 1 MB minified to a browser bundle (the exact figures and the committed measuring config are #48's).
- **ADR-0004, the Go adapter** (#49, accepted as amended in #55): CloudWeGo Eino's ADK chosen over ADK for Go on measured grounds; a `go/` module (standard library only until the Eino adapter; its dependency graph held to an exact-version allow-list) with the contract's types generated by the repository's own generator (every vector item round-trips, and a dropped member fails the round trip), a Go certification runner that speaks to the TypeScript suite's own scripted server, a parity table holding the Go checks in step with the TypeScript leg, and a `go` CI job.
- **The Go gate** (`go/gate`, #55): the port of the tool gate, held to the same vectors as the TypeScript gate — three new hand-written vector families: two of them (`gate-frames`, `phase-offers`) hold both gates; the third, `approval/grant-states`, holds the Go gate and the schema (the TypeScript harness carries no approval reader); an adapter receives a narrow handle (`CallTool`, `AdmitHost`, the critic's and the reformat run's begin and end) and never the host's phase controls; a child started in plan mode holds plan's reads only; an unoffered name never reaches the transport.
- **The Eino adapter** (`go/adapter/eino`, #57, the Go train's third step): the server-side adapter on CloudWeGo Eino's ADK, dispatching every tool through the Go gate's narrow handle with a turn's calls run in the model's order; its only way out is `go/relay`, an in-process client whose handler is a line-by-line reading of the Desk's relay handler (the four slots, the body bound, both deadlines, a transport that follows no redirect, reflected credentials stripped); the package's context, budget, recall rule and events ported to Go and held to the same vectors; delegation by the package's own coordinator with children bounded by the connection's concurrency and their test calls charged to the parent's turn, safe under the race detector; the Go certification passing every leg the TypeScript suite runs on a model engine, and the six scenarios, with `go/cmd/harness-check` to run it against a given server; an exact-version allow-list of modules. Not yet bound to the Desk's own relay handler: that binding is the Desk's.
- The LOW findings filed by the reviews of this release's pull requests carry over: #45 (the pre-release review of v0.2.0), #48 (the Deep Agents adapter's bundle figures and the question pause's wording), #58 (the Eino adapter's transport check and size figure); #54, the delegation-concurrency test's timing flake on the deepagents leg, is open.

## What the Desk must do to adopt it

judgment-pack-desk#526 (a harness-engine choice on API connections: Vercel AI SDK or Deep Agents, loaded through the package's certified engines) and #529 (the Desk's approval handling held to `approval/grant-states.json`). The Go adapter is not yet bound to the Desk's relay handler; that binding is the Desk's and follows the Go train's last step.

## What it does not hold

the binding of the Go adapter to the Desk's own relay handler (the Desk's), the Desk's adoption of this release (judgment-pack-desk#526, #529, #533), the deepagents delegation-concurrency test's timing flake (#54), and the refusal text's trailing-period change named in #
