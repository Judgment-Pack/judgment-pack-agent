# v0.14.0

Release notes for v0.14.0. This document describes the release contents and the gates that
must be satisfied before publication. The package is `@judgment-pack/harness`. A completed
release publishes its attested npm tarball and checksums and creates the matching Go module tag
`go/v0.14.0` on the release commit for module `github.com/Judgment-Pack/judgment-pack-agent/go`.
The package version and lockfile identify v0.14.0. Publish only after the release procedure
verifies the package, checksums, attestations and matching Go module tag.

The host migration details are in the [host upgrade guide](../upgrade/v0.14.0.md).

## Release scope

v0.14.0 fixes the durable agent wire's approved continuations, bounds what a tool source's schemas
keep as written, fences goal commands, adds successor runs and question-wait continuations, and
extends the record guard to the results, reads and failure details a durable run stores. No record
format changes version. A host that uses none of the new features sees v0.13.2's bytes on the wire
and in its records, apart from the changes the upgrade guide states for every host (each section
names its own), among them the approval block's last member `decidedAt` (#309), the redacted form a
durable run records of a call's result (#343), of a Runtime read and of a failure's detail (#352),
and the bounds on what a tool source's schemas keep as written (#308).

- **The durable agent wire** (#309, #317, PR #354). The request after the person's decision
  carries the approved call's result, and the block's data ends with `decidedAt`. Under task steps
  the approved continuation goes on to the end, a Plan decision after an answered approval goes on,
  and a Plan decision whose continuation delegates goes on. In Go, a native Plan decision's
  checkpoint is stored as canonical text.
- **Source schemas** (#308, PR #356). A source past the bounds on the words its schemas keep as
  written (64 enum members, 64 names or `required` entries per object, 4,096 bytes across its
  tools) is a catalogue whatever the budget. A lone surrogate in an `enum` or `const` is dropped
  with a guardrail. Go keeps schema bytes that are not UTF-8 as U+FFFD, as TypeScript does and as
  v0.13.2 did, and the catalogued paths have tests for a lone surrogate (part of #357, PR #363).
- **Goal commands carry a worker's fence** (#315, PR #359), and the goal conformance kits hold a
  host store to the fence rules (#361, PR #366), including the same owner's earlier epoch and other
  principals (part of #368, PR #369).
- **Successor runs and a claimed question wait's continuation** (#340, #341, PR #355). Every
  continuation of a `complete` head is fenced. A
  successor's create fails closed on a store value that hides the lease port, the wait export or
  the deadline reader, and every later open on one that hides the wait export or the deadline
  reader (#362, PR #366).
- **The record guard.** A redacted durable host or Runtime result is committed and answered in its
  redacted form (#343, PR #350). A durable run's Runtime reads, the chat read cache, entries read by
  id and a handoff's answer are recorded and served in the guard's form, and so is a call's or a
  model's failure detail, which is read whole before it is cut (#352, PR #365). A failure detail is
  read whole as far as a fixed margin past the cut, and on every use of the same error (#367,
  PR #370).
- **Asks saved before they are shown** (#342, PR #346; #349, PR #360). A custom source's ask, and
  on every engine a Runtime action's ask, is saved paused before it is shown. One that cannot be
  saved ends the run `unknown`/`storage`/`unknown`.
- **Job batch LOWs** (#323, PR #360). A cancel whose host throws after the hand-over reads as
  maybe sent, and a cancel ask that disagrees with what the writer saw of the job is refused.
- **A critic's and an author-test child's evaluation is a rehearsal** (#344, PR #353).
- **Malformed record headers** (#358, PR #363). Go refuses a record that lacks a header member,
  where it panicked.
- **Undici 7.30.2 and 8.12.4** (PR #351), below.
- **CI.** Main CI compares each job's recorded tools with its pins right after the capture (#338),
  the check job's setup-node is unconditional (#334), a mutant that stops a test file from loading
  is reported `BROKEN` (#320), and the certification suite runs from any directory (#345), all in
  PR #347; three LOWs from its review (#348, PR #363). The job tests' binary is split in two, with a
  fourth race leg, `go-race-d` (PR #364).

Dependency files changed since v0.13.2 only where PR #351 moved Undici, in `dev.json`'s race steps
(PR #364), and in the package's version. `package-lock.json` changes the two Undici records
(`node_modules/@ai-sdk/provider-utils/node_modules/undici` from 7.30.1 to 7.30.2, and the
development-only root `node_modules/undici` from 8.12.2 to 8.12.4, each in its version, resolved
and integrity) and the package's version. `go/go.mod`, `go/go.sum`, `package.json` and
`requirements-dev.txt` are identical, and `packages/harness/package.json` changes only the
package's version. `dev.json` changes only its race steps (PR #364): `go-race-b`'s exclusion adds
`./adapter/jobsendtests`, which a new `go-race-d` step runs; no tool pin changed. The six
advisories 7.30.2 and 8.12.4 patch are in the
[dependency advisory policy](../security/dependency-policy.md).

Fixed in this release, from v0.13.2's known limitations: #309, #317, #308, #315 and #323 LOW-1.

## Host review before pinning (upgrading from v0.13.2)

Read the [host upgrade guide](../upgrade/v0.14.0.md) for each migration. The points a host must
review are:

1. **Goal fences.** A host store kind checks `transition.fence` in `commandGoal` against its own
   leases and passes `runStoreGoalConformance` (Go `CheckRunStoreGoalConformance`). One built on
   the package's goal table passes its own lease check to it, or fenced goal commands are refused
   `GoalCapabilityRefused` `store-unsupported`.
2. **A claimed job wait's continuation.** At a `complete` head it is admitted only through the
   claim's fenced view; through any other store it is refused `RunComplete`.
3. **Run ids that begin with `successor-`.** An open at such an id without its successor input is
   refused `SuccessorRefused` `unbound`.
4. **A store wrapper and successors.** A store value that hides the lease port, the wait export or
   the deadline reader is refused when a successor is created through it, unless it declares itself
   unleased, which is the host's attestation. Every later open is refused where the wait export or
   the deadline reader is hidden.
5. **The approval block.** A host that reads the approval continuation's data accepts a last
   member `decidedAt`.
6. **Text a host matches.** The guardrail for a dropped `enum` or `const` and the refusal of a
   call missing a `required` member read differently, and a source past the schema bounds is a
   catalogue.
7. **Failure codes.** An ask that could not be saved ends `unknown`/`storage`/`unknown` on every
   engine.
8. **Redacted forms.** Under redaction on store, results, reads and failure details reach the
   model and the records in the guard's form, and in TypeScript the `AIFailureError` a tool threw
   is given that form in place.
9. **Go Plan decisions stored by v0.13.2.** On a store that keeps the run's history, such a run
   stays refused `HistoryInputInvalid`; start a new run for its work.
10. **Undici in the host's lockfile.** The package's manifests do not require Undici 7.30.2; a
    host keeps its own resolution at 7.30.2 or later.

## Known limitations, moved to v0.15.0

- **#304's remainder.** A child's time limit stops a task-steps run instead of failing the task.
  It is reported `cancelled` ("The response was stopped.") though nobody stopped it, it can emit
  two errors for one cause, and the child's durable commit time counts against the limit. The
  run fails closed, and its head stays `running`.
- **#286.** Through the `vercel` engine on Gemini, a number past what a double holds runs as
  `null`, before the harness reads the arguments.
- **#357's remainder.** For a lone surrogate in a property or definition name, a `required` entry,
  a `$ref`, a description or a tool name, Go offers U+FFFD and TypeScript writes the `\ud8xx`
  escape, so the offered text and `offeredSchemaBytes` differ between the languages. Each case
  fails closed, and no bound is bypassed.
- **#368's remainder.** `leasedViewOf` is reachable through the package's `./*` export; `moved`
  does not stick after a raw store commit during a successor's create; the re-authorization
  continuation's refusal at a succeeded head has no test or row of its own; the goal kits differ
  on wrapped errors (Go accepts `%w`, TypeScript refuses a cause-wrapped one); and TypeScript's
  `durableSession` reads a continuation member of its input more than once, where Go reads one
  copy. Admission still goes through the claim, so nothing runs twice. The issue also keeps two Go
  lines it names and the three LOWs of PR #369's review.
- **#371.** In Go, the `failure.RecordedError` a durable call returns holds no whole detail, so a
  host that hands it to a second writer has only its recorded form guarded. In TypeScript a second
  writer reads the first guard's form, so a pattern of its own that overlaps one of the first
  guard's redactions can leave part of its match. One oversized or refused chat entry fails every
  all-items search of a durable run. Events are stored without the guard.
- **#161.** `braces` stays on the path through `deepagents` (pinned at 1.14.1): the latest
  `deepagents`, 1.16.4, still depends on `micromatch` and `fast-glob`, and the upstream removal
  candidate is unmerged. [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)
  remains withdrawn, with no patched version. The dependency is retained, and nothing claims the
  library is repaired.

## Release prerequisites

- **Go dependency disclosure (#192).** [GO-2026-5932](https://vuln.go.dev/ID/GO-2026-5932.json)
  (`golang.org/x/crypto`, the OpenPGP family) and
  [GO-2026-5781](https://vuln.go.dev/ID/GO-2026-5781.json) (`rsc.io/pdf v0.1.1`) remain in the
  Go module graph. `go/go.mod` and `go/go.sum` are unchanged since v0.13.2, which selects
  `golang.org/x/crypto v0.58.0`, `rsc.io/pdf v0.1.1` and `golang.org/x/arch v0.11.0`. Upstream,
  checked 2026-11-10: the latest `golang.org/x/crypto` tag is `v0.58.0`, and the advisory records
  the module fixed only from an untagged commit; the latest `golang.org/x/arch`, `v0.33.0`, still
  requires `rsc.io/pdf v0.1.1`. The current exception, the maintainer's narrow renewal of
  2026-11-04, covers Agent v0.13.2 and go/v0.13.2 only and expires at the publication of Agent
  v0.14.0 or 2026-12-07 00:00 UTC, whichever comes first
  ([renewal](https://github.com/Judgment-Pack/judgment-pack-agent/issues/192#issuecomment-6641621637)).
  No exception covers v0.14.0. The renewal's remedy for v0.14.0 is to move to the first tagged
  `golang.org/x/crypto` release that contains the fix, and to remove or replace the path to
  `rsc.io/pdf` (Sonic, then `golang.org/x/arch`); neither is done in this release.

  review for PRs #346, #350, #353, #354, #355, #356, #359, #365, #366 and #370, and a narrow review
