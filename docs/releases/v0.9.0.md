# v0.9.0 (unreleased)

## What it adds

- Omitted native reasoning now remains omitted and uses the selected model's default;
  explicit `none` is no longer synthesized.
- Resolved policy events and checkpoints record reasoning provenance as `layer`,
  `model-default`, or `discovered`.
- Hosts may provide authenticated model reasoning discovery. Unsupported explicit
  run and project values are refused before generation. A table value is a default:
  it stays when advertised, otherwise it uses the discovered default or remains
  omitted when discovery advertises none.

Without discovery, v0.9.0 admits every policy/session case in the v0.8.1 comparative
matrix. An omitted author preference now leaves the request member absent; an author
preference that was set produces the same request member. This includes run-only child
and sub-agent `off`/`none` values, with or without project authorization, and delegated
profile and declared sub-agent roles. Known author tiers retain their existing ceiling.

## Compatibility

Upgrade is supported: v0.9.0 reads v0.8.1 policy members and checkpoints, treating a
historical member without `source` as layer-supplied. Downgrade is asymmetric because
v0.9.0 records may carry `source`: v0.8.1's closed Go decoder rejects those members,
while its TypeScript checkpoint reader accepts them. Do not run v0.8.1 readers against
v0.9.0 checkpoints.

The release publishes the Go module as
`github.com/Judgment-Pack/judgment-pack-agent/go@v0.9.0` alongside the harness
package.
