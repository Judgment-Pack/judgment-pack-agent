# v0.9.0

A release of `@judgment-pack/harness`, as an attested package asset and a Go module tagged by the release workflow. One contract change.

Install the tarball from this release and pin it by the digest in `checksums.txt`; the Go module by `go get github.com/Judgment-Pack/judgment-pack-agent/go@v0.9.0` with `go.sum` committed.

## What v0.9.0 holds

- **An omitted reasoning preference means the model's default, and stays omitted** (#142, pull request #145; amends ADR-0011 and ADR-0012). v0.8.x turned an omitted native author effort into an explicit `none`, which a host whose discovered model does not advertise `none` rightly refused. Now an omitted `models.<role>.reasoning` resolves to no value and the provider request omits the effort member, for the model author, the model critic, the agent author, the fallback and delegated child runs, in TypeScript and Go; `none` is only ever an explicit layer's choice, checked like any other value.
- **Provenance.** The resolved member carries `source` (`layer`, `model-default`, `discovered`), recorded by the `policy_resolved` event and the checkpoint, so a resumed run rebuilds the same request bytes.
- **Optional host discovery.** A host that knows the selected model's advertised set may supply it (`models.<role>.discovered.reasoning: {default, supported}`) before admission: an omitted preference then takes the advertised default, and an explicit value outside the set is refused before any generation, never replaced.

## Unchanged

Precedence (chat over project over table), the wire contract's other members, every other ADR. Hosts that never supply discovery see no refusal that v0.8.1 did not make, and no `none` they did not write.

## The supported way to consume the package

Through a bundler. Native Node ESM import is tracked as #143 and is not part of this release.
